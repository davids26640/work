# Filter & Belt Tracker

A view-only tracker for the plant's ash houses, air handlers, rooftop units and heaters. It lists each unit's filter and belt sizes, filter and belt stock, what to order, cooling capacity and notes.

This public copy contains **no filter or belt change dates**. Those are tracked privately and are never uploaded here.

## Files
- `index.html`: page layout
- `styles.css`: look and colors
- `app.js`: code
- `data.js`: the data (replaced on each update)

## Updating the site
1. On the private tracker, click **Copy for GitHub** and press **Copy**.
2. Here on GitHub, open `data.js` and click the pencil icon (Edit).
3. Select everything, delete it, paste, and click **Commit changes**.

Only `data.js` changes on a normal update. Never upload a `data.js` from anywhere else, because only the "Copy for GitHub" version has the dates stripped out.
